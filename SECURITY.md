# Security Policy

## Scope

StayMic is a menu bar utility that reads and writes CoreAudio device
properties (input volume, default input device). It does not record,
process, or transmit audio, and it does not run a network server or
client of any kind.

## Reporting a vulnerability

If you believe you've found a security issue in StayMic, please report
it privately rather than opening a public GitHub issue:

- Use GitHub's [private vulnerability reporting](https://github.com/2nm-studio/staymic/security/advisories/new)
  for this repository, if enabled, or
- Open a draft security advisory, or contact the maintainers directly
  through the 2NM Studio GitHub organization.

Please include the macOS version, StayMic version, and steps to
reproduce. We'll acknowledge reports as soon as we can and keep you
updated as a fix is developed.

## Supported versions

Only the latest published release is supported with security fixes.
